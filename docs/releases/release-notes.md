# 发布记录

### 2026-10-23

- Vertex 账号支持设置配额上限、按配额参与调度，并在账号列表展示每日、每周及总配额进度。
- 账号列表记住平台和状态筛选条件，保留自定义分组标签页与筛选项显隐控制。
- Gemini 系列接口遵守分组的生图开关，新建 Gemini、Antigravity 和 Grok 分组默认允许生图；升级时已有 Gemini 和 Antigravity 分组的生图开关会设为开启。
- Gemini 与 Anthropic 兼容流式请求在客户端中途断开时保留已收集的用量并计费；上游异常结束时返回错误，避免把不完整响应作为成功结果。
- OpenAI 请求在尚未输出内容时保留过载及空流重试能力，统一出站客户端身份；Cloudflare 1010 拦截与普通模型限流分开处理。
- 改善工具参数常量与注解的兼容转换，避免 DeepSeek 图片请求重复携带图片数据，并统一异步生图的图片下载策略。
- Grok 4.7 Fast 使用对应 Fast 价格计算费用，Gemini 缓存命中且提示词被拦截时避免产生负输入 Token 数量。
- 优化账号调度快照、模型映射与配额累加，更新前端内容净化依赖。

### 2026-10-16

- 支持 Gemini 4 Argon 的模型选项与费用计算，补充 Claude 5.5 分档基础价格。
- Gemini 兼容接口支持传递思考档位与预算并返回流式推理摘要；Antigravity 转发保留工具结果图片、原生函数调用和思考签名。
- OpenAI API 密钥账号可以在 Messages 接口中模拟联网搜索；Anthropic 协议转发使用账号配置的服务地址，并支持配置兼容请求的最小输出 Token 数量。
- ChatGPT OAuth 账号停用 GPT-5.5 的目录展示与调度，API 密钥账号继续支持该模型；Responses 兼容响应补齐创建时间，改善流式响应兼容性。
- Codex 账号导入按工作区隔离，复合平台路由拒绝归属不明确的模型，减少协议误路由。
- Vertex 服务账号不存在时标记账号异常并切换账号，共享容量限流时支持在同一账号上退避重试；修正 GLM CodingPlan 的五小时与每周用量窗口。
- EasyPay 支付通知在入账前向上游确认订单，订单创建校验订单类型；退款处理中预留退款金额，失败时回退，并改进支付宝退款状态确认。
- Stripe 支付恢复使用订单保存的支付信息；账号筛选项恢复直接显示，保留自定义分组标签页与筛选项显隐控制。

### 2026-10-13

- 支持 Claude Haiku 5.5 的网关调用、模型选项与费用计算。
- Gemini 支持显式上下文缓存及缓存存储计费；Agent Platform (Vertex) 账号支持 API 密钥认证、模型列表查询与同步，并保留工具结果中的图片。
- 管理员可以为分组名称与描述配置多语言译文，用户界面按所选语言展示。
- 临时不可调度规则可以选择作用于整个账号或指定模型，便于隔离单个模型的上游错误。
- Responses 转 Chat Completions 时保留请求语义并限制不安全重试；Codex 图片工具桥接仅作用于 OpenAI 账号。
- GPT-6.1 Sol 的 Codex 配置默认上下文窗口为 500,000 个 Token，订阅计费免除该模型的长上下文附加费。
- 渠道监控设置支持添加缺少的平台，自动刷新会重新获取可用性详情；运维请求详情显示账号名称。
- 支付倒计时按实际经过时间计算，选择框在输入法组合输入期间保留键盘操作，账号列表完整显示分组名称。

### 2026-10-09

- 管理员可以接入 Cline 和 Command Code 账号；账号表单与模型同步入口会根据平台支持的能力显示对应选项。
- 账号列表提供紧凑的搜索与筛选布局；展开更多筛选时可以查看类型、隐私模式等条件，收起后仍能看到启用数量。
- 用量详情显示单次请求的输出速度；运维看板提供输出速度的中位数、低分位数和平均值。
- 已建立的 Responses WebSocket 连接在分组倍率变化后，下一轮请求按当前费率结算；远程 Codex 模型发现遵守账号模型映射。
- Responses 联网搜索及 Anthropic 兼容调用更准确地保留工具选择、开发者消息、拒答与思考内容。
- 离开 Stripe 或 Airwallex 支付页面后，延迟完成的初始化不会再启动支付组件或新轮询。
- 同时打开多个弹窗时，Escape 仅作用于最上层弹窗；详情全屏时先退出全屏。

### 2026-10-07

- 首次安装时，留空管理员邮箱和密码即可自动生成随机登录凭据，并可在首次启动日志中查看；手动填写的邮箱和密码会进行有效性校验。
- EasyPay 支付回调会校验通知参数，防止伪造付款成功通知；支付返回地址中的自定义查询参数不会参与回跳链接。
- 使用远程模型目录生成 Codex 客户端配置时，会启用 API 密钥模型发现，以便获取可用模型。

### 2026-10-03

- 可以使用 TypeSafe API 密钥账号，通过原生 `/v1/systemone` 接口调用 `jev-latest` 模型；不兼容的网关协议不会转发到 TypeSafe 账号。
- 管理员可以设置按充值金额生效的赠金或折扣档位与活动文案，充值页面、订单详情和支付结果会显示对应优惠。
- 管理员可以在账号列表中直接调整优先级；用户可以按分组名称排序 API 密钥。
- 请求完成前删除 API 密钥时，已产生的用量仍可正常结算。
- Grok CLI 请求使用匹配当前客户端的身份请求头，改善上游兼容性。

### 2026-09-30

- 支持 GPT-6.1 Sol 的模型识别、Codex 模型目录和价格计算。
- 管理员查询 Claude OAuth 账号的可用重置次数后，可以确认使用一次原生额度重置；服务端校验可用性并防止重复领取。
- 单个用户默认最多保留 200 个 API 密钥，每小时最多创建 60 次；管理员可以调整或关闭限制。
- Codex 客户端配置支持远程模型目录，也可以选择下载本地目录；目录过大时自动改用本地文件。
- 余额模式会为在途请求预留预计费用，降低并发请求同时透支余额的风险。
- Claude Code 专用分组配置降级分组后，其他客户端的 Chat Completions 和 Responses 请求可以走降级分组。
- OpenAI 账号的订阅档位显示增加 Pro 100、Pro 200、Pro 500，以及更多 Business、Enterprise 和教育版档位。

- 上游管理页在宽屏下将余额通知信息与搜索操作并排展示，在较窄屏幕上自动堆叠，便于管理员快速浏览和操作。

### 2026-09-23

- 上游管理页采用更紧凑的搜索、余额通知和状态统计布局，并优化上游卡片的信息层级与移动端显示。
- 关闭上游资源对话框时会终止仍在进行的流式请求，避免请求在后台继续运行。

### 2026-09-19

- 管理员配置 Sub2API 上游时可以直接填写访问令牌和刷新令牌，复用已有登录会话并避免重复触发交互式人机验证。
- Sub2API 上游优先复用有效访问令牌，仅在实际认证失败后使用刷新令牌或账号密码重新认证。
- NewAPI 资源密钥失效时，模型刷新会自动重新获取并保存资源密钥后重试；上游 HTTP 状态会以不含敏感响应正文的摘要返回给管理员。
- 上游管理请求支持读取标准代理环境变量，便于在需要出站代理的部署环境中查询上游信息。

### 2026-09-15

- 用户可以在“快速体验”页面选择自己的 API 密钥和可用模型，直接进行流式对话，并随时停止生成或清空当前会话。
- 管理员可以按 API 密钥名称模糊筛选提示词记录，便于定位指定密钥产生的调用。

### 2026-09-13

- 提示词记录仅接收 Responses、Messages 和 Chat Completions 三类用户调用，过滤内存整理、上下文压缩、标题生成和系统后台请求等无关内容。
- 管理员可以按会话编号筛选记录；列表显示总记录数，移除处理状态信息，并支持一键清空全部提示词记录。
- 提示词记录保存请求的会话编号，同一会话的多次调用分别保留并能正确关联响应内容。
- 即使关闭请求头保存，提示词记录仍保留会话编号，便于按会话查找并关联调用记录。
- 单次请求包含较长消息历史时，提示词记录仅保留最新 30 条消息，控制存储规模并保留最近上下文。

### 2026-09-12

- 提示词记录新增 0 至 3650 天的保留期限，默认 0 表示永久保留；新记录自动设置到期时间，过期记录分批清理，历史记录的到期时间保持不变。保留天数设置与总开关并排显示，缩短列表前的操作区。
- 提示词列表改用上一页、下一页的游标翻页，保留模型子串筛选，并增加处理字节、请求与响应丢弃、保存失败和清理情况统计；过时请求会取消且不再显示错误提示。
- 大请求记录减少处理耗时与内存开销，高峰期限制待保存内容；响应等待对应请求保存后回填，正常停机等待已接收的记录处理完成。
- 提示词详情兼容历史正文；带路径的 AGENTS.md 预设可以过滤，大响应保留已捕获的文本并明确显示不完整状态。
- 配置说明与详情明确响应记录支持 HTTP JSON/SSE，WebSocket 当前仅保存各轮请求。
- 管理员可以分别控制提示词记录中的请求头、提示词和响应内容；关闭响应保存后，后续调用不会缓存或提取响应文本，历史记录保持不变。
- 管理员启用“过滤预设”后，记录会移除 Claude 内部推理及签名，并可分别控制是否过滤用户的 AGENTS.md/CLAUDE.md 预设和已注册技能信息；两个子过滤开关默认开启。
- 提示词调用详情支持一键复制完整请求体；图片、音频、视频和文件等多模态大文件内容不会写入提示词记录。
- 提示词记录异常会被独立处理；即使内容解析、排队或保存失败，模型调用和上游响应也会继续正常返回。

### 2026-09-11

- 管理员可以在提示词记录列表查看调用摘要，点击行操作后在详情弹窗中查看请求内容和从响应中提取的文本。
- 提示词记录支持按用户和调用时间筛选，并支持单条删除与批量删除。
- 提示词记录列表提供独立的“记录请求与响应”开关，关闭后不再保存新的请求和响应记录。
- 管理员可以在账号编辑页面选择可查看该账号的用户。
- 普通用户可以通过账号管理查看获授权的账号，并使用筛选、列设置、自动刷新、排序记忆和分页功能。
- 普通用户账号列表保留连接测试与统计查看入口，不提供编辑、删除及其他账号写操作。
- 普通用户可以在账号列表查看授权账号的用量窗口，窗口仅提供只读信息。
- 管理员与普通用户的账号分组选项卡支持长按拖动排序，“全部分组”和“无分组”固定在首尾，排序结果仅保存在当前浏览器。
- 管理员与普通用户的分组选项卡会根据可用空间显示，超出部分收纳到“更多分组”菜单，避免出现横向滚动条。
